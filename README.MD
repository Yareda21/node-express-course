## Repository Structure

This repository contains a comprehensive collection of Node.js and Express.js tutorials and exercises, organized in a progressive learning path:

1. **Basic Node.js Concepts**

    - `01-node-tutorial`: Introduction to Node.js fundamentals
    - `02-express-tutorial`: Getting started with Express.js

2. **Core Applications**

    - `03-task-manager`: Building a task management application
    - `04-store-api`: Creating a store API
    - `05-JWT-Basics`: Understanding JSON Web Tokens
    - `06-jobs-api` & `06.5-jobster-api`: Job board API implementation

3. **Advanced Features**
    - `07-file-upload`: File handling and uploads
    - `08-send-email`: Email functionality
    - `09-stripe-payment`: Payment processing with Stripe
    - `10-e-commerce-api`: Complete e-commerce API
    - `11-auth-workflow`: Authentication workflows

Each folder contains a self-contained project that builds upon previous concepts while introducing new features and best practices in Node.js and Express.js development.
